# 제품 스펙

## 한 줄 요약
**속기사가 한글에서 회의록 작성 중 단축키 한 번으로 우리말샘 사전을 띄우는 도구.**
로컬 HUD 앱(.exe)이 핵심 도구이고, SaaS는 그 인증·검색·배포 백엔드.

## 문제

### 현재 속기사의 회의록 작성 워크플로
1. 회의 음성을 들으며 한글에 빠르게 타이핑
2. 모르는 단어 또는 헷갈리는 표기를 마주침
3. **Alt+Tab → 브라우저 → opendict.korean.go.kr 접속 → 검색어 타이핑 → 결과 확인 → Alt+Tab으로 한글 복귀**
4. 이 과정만 매번 10~20초 소요. 회의 한 편에 수십 번 발생.

### 핵심 페인포인트
- **Alt+Tab 빈도**: 흐름이 끊김 + 손이 키보드에서 떨어짐
- **검색어 다시 타이핑**: 한글에서 본 단어를 또 입력해야 함
- **외부 사이트 의존**: 광고·UI 변경·로딩 지연

## 해결

### 핵심 기능 (로컬 HUD)
- **F2 (블록 선택 검색)**: 한글에서 단어를 마우스로 블록 잡고 F2 → HUD에 즉시 결과
- **F3 (이전 단어 자동 검색)**: 커서 앞 단어를 자동으로 잡아 검색 (블록 안 잡아도 됨)
- **HUD 오버레이**: 한글 위에 반투명으로 떠있어 Alt+Tab 0회
- **클릭 통과 모드**: HUD를 옆에 띄워두고 한글 클릭 가능

### 보조 기능 (SaaS)
- 가입/관리자 승인 (베타 운영용)
- 사용자별 API 키 발급 (로컬 HUD가 SaaS 인증)
- 검색 통계 대시보드 (사용 패턴 시각화)
- 다운로드 페이지 (.exe 호스팅 + 사용법 안내)

## 타겟 사용자

### 1차 타겟
**한글 워드프로세서로 회의록을 양식 맞춰 작성하는 속기사**
- 회의·강연·면담 속기 전문가
- 양식이 정해진 문서를 작성 (단순 글쓰기가 아님)
- 단어 정확도가 중요 (예: 한자어, 전문용어)

### 2차 타겟 (Phase 향후)
- 학술 글쓰기 전문가 (논문, 보고서)
- 한국어 교사·번역가

### 비-타겟
- SaaS 안에서 글쓰는 시나리오 (TipTap 워크스페이스 같은 것). 한글이 아니면 양식·기능 부족.
- 비기술 일반인 (HUD 설정·단축키 개념이 익숙해야 함)

## 비즈니스 모델

### Phase 1년차: 무료 운영
- 모든 기능 무료
- 친구·지인 속기사 네트워크에서 입소문으로 사용자 확보
- 사용 패턴 데이터 수집 (어떤 단어 자주 검색하나, 사용 빈도 등)

### Phase 2년차: 유료화 lock-in 도입 (예정)
- 무료 사용자는 일일 검색 횟수 제한 (예: 50회/일)
- 구독자(월 N원)는 무제한
- 유료화 인프라는 이미 갖춰짐:
  - 모든 검색이 SaaS를 거치므로 사용량 정확 측정 가능
  - 사용자별 API 키로 즉시 차단 가능
  - Stripe 연동만 추가하면 됨

### 왜 lock-in이 가능한가
- 우리말샘 API 키는 **바다 1개**로 통일 → 사용자가 우회 불가
- 로컬 HUD가 SaaS를 통과해야 검색 가능 → SaaS 측에서 권한 결정

## 시장 검증

- **MVP**: 로컬 데스크톱 버전(`C:\app\hudtyping`) 이미 완성
- **사용자 피드백**: 친구·지인 속기사들에게 배포한 결과 "다들 좋다고 함"
- **이번 SaaS**: MVP를 더 많은 사용자가 쓸 수 있게 인증·배포·통계 인프라 추가
