# 제품 스펙

## 핵심 가치

hudtyping은 속기사가 한글 문서 작성 중 Alt+Tab 없이 우리말샘 검색 결과를 HUD로 확인하게 하는 Windows 데스크톱 보조 도구다.

## 핵심 사용자

- 회의록, 녹취록, 강의록 등을 한글 문서 양식에 맞춰 작성하는 속기사
- 문서 작성 흐름을 끊지 않고 단어 뜻, 표기, 한자 정보를 확인해야 하는 사용자

## MVP 기능

### 로컬 HUD 앱

- Windows Electron 앱
- 한글 문서 위에 작게 띄워 쓰는 HUD
- 커서 앞 검색 단축키 제공
- 같은 단축키를 연속 입력하면 띄어쓰기를 넘어 검색어 확장
- 직접 검색어 입력 보조 기능
- API 키 입력, 투명도 조절, 클릭 통과 모드

### 커서 앞 검색

블록 검색은 MVP 기본 기능에서 제거한다. 제품의 핵심은 사용자가 블록을 잡지 않아도 되는 것이다.

```text
회의 안건 정리|
```

- 1회 입력: `정리`
- 2회 입력: `안건 정리`
- 3회 입력: `회의 안건 정리`

v0.2.2부터는 검색 결과를 기다린 뒤 확장하지 않고, 단축키 입력 횟수만큼 먼저 확장한 뒤 한 번만 검색한다.

### SaaS

- Clerk 인증
- 관리자 승인
- 사용자별 API 키 발급
- 월 검색 한도
- 검색 로그와 통계
- 인기 검색어, 시간대별 검색량, 사용자별 검색 이력
- Redis 단기 캐시 + Neon 장기 사전 캐시

## 차별점

| 항목 | hudtyping | 우리말샘 웹 직접 검색 |
| --- | --- | --- |
| 작업 흐름 | 한글 문서 위 HUD | 브라우저 Alt+Tab 필요 |
| 검색어 입력 | 커서 앞 자동 캡처 | 직접 입력 |
| 연속 확장 | 가능 | 불가 |
| 사용자 통계 | 가능 | 불가 |
| SaaS 운영 제어 | 가능 | 불가 |

## 운영 원칙

- 빠른 응답이 가장 중요하다.
- 사용자 UI에서는 기능 이름을 업무 언어로 표현한다.
- `블록 검색`, `이전 단어 검색` 같은 내부 구현 중심 표현은 노출하지 않는다.
- 사용자에게는 `커서 앞 검색` 하나로 설명한다.
