# PlaySteno 브랜드·콘텐츠 기준

**확정일**: 2026-08-06

## 브랜드 계층

- 공식 홈페이지와 canonical 주소: **https://playsteno.com**
- `papawheels.vercel.app`은 기존 앱과 옛 링크를 위한 호환 주소이며 외부 안내에 사용하지 않는다.
- 최상위 브랜드와 전체 사이트 이름: **PlaySteno**
- 현재 공개 제품: **낱말지기 온라인**
- 향후 유료 제품: **낱말지기 로컬버전**
- 로컬버전은 판매 준비가 끝날 때까지 공개 페이지에 노출하지 않는다.
- 커뮤니티 기능과 명칭은 보류한다. 현재 카카오톡 오픈톡방은 **공지·지원 채널**로만 설명한다.

## 현재 공개 가능한 제품 사실

- Windows 10·11용 HUD 앱
- 기본 월 검색 한도 500회
- 매월 1일 0시 UTC(한국시간 오전 9시) 초기화
- 커서 앞의 복사 가능한 텍스트를 검색
- 같은 검색 단축키를 연속 입력하면 앞 어절까지 검색어 확장
- 뜻풀이 클릭 또는 `Ctrl+Alt+E`로 예문 창 표시
- `Ctrl+Shift+H`로 HUD 표시·숨김
- 연결 코드는 10분 동안 유효한 1회용 코드이며 최초 연결 이후에는 다시 로그인하지 않아도 됨
- 새 버전은 앱에서 안내하며 재시작할 때 적용
- 현재 설치 파일에는 코드 서명 인증서가 적용되지 않음

## 공개하지 않는 내용

- 낱말지기 로컬버전의 가격·출시일·구매 방법
- 준비되지 않은 타자게임·자료실·굿즈·회원 커뮤니티 메뉴
- 내부 수익화 전략
- 구현으로 검증되지 않은 절대 속도나 호환성 표현 (`0ms`, `모든 프로그램` 등)

## 문체

- 차분하고 자신감 있는 업무 언어를 사용한다.
- 사용자를 꾸짖거나 불안하게 만드는 문구를 피한다.
- 내부 구현 용어보다 사용자가 하는 행동과 얻는 결과를 먼저 설명한다.
- 보안·설치 안내는 단정적인 안전 보장 대신 확인 가능한 출처와 대응 절차를 제시한다.

## 확장 원칙

- 두 번째 실제 서비스가 출시되기 전까지 `/`는 낱말지기 온라인 중심으로 유지한다.
- 공개 페이지는 `(marketing)` 라우트 그룹의 공통 헤더·푸터를 사용한다.
- 두 번째 서비스 출시 시 `/`를 포털 홈으로 전환하고 낱말지기 상세를 `/natmalgi`로 이동한다.
- 기존 공개 URL은 영구 리다이렉트로 보존한다.
