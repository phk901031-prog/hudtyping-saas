# 사용자 매뉴얼 — SaaS 사용법

> 이 문서는 hudtyping을 처음 쓰는 속기사를 대상으로 한다.
> 로컬 HUD 설치 가이드는 [local-hud-setup.md](local-hud-setup.md)에 따로 있다.

## 처음 시작 (5분)

### 1단계: 가입
1. **https://hudtyping-saas.vercel.app** 접속 (Phase 7 배포 후 정식 도메인 안내)
2. 우측 상단 **"회원가입"** 클릭
3. 다음 둘 중 선택:
   - **이메일 + 비밀번호**: 가입 시 입력한 이메일로 인증코드 받음
   - **Google 계정으로 가입**: 클릭 한 번으로 끝

   *📷 이미지 자리: `screenshots/01-signup.png`*

### 2단계: 승인 대기
가입 직후 자동으로 **"승인 대기 중"** 화면이 나옴.

> 베타 운영 단계라 관리자가 직접 가입을 검토해. 보통 1~24시간 안에 승인되고, 승인되면 이메일로 알려줘.

   *📷 이미지 자리: `screenshots/02-pending.png`*

### 3단계: 승인 후 로그인
승인 알림 받으면 다시 로그인. 자동으로 **대시보드**로 이동.

   *📷 이미지 자리: `screenshots/03-dashboard.png`*

대시보드에 4개 카드:
- 🔍 **우리말샘 검색** — 웹에서 직접 단어 검색
- 🔑 **API 키** — 로컬 HUD 앱 인증용 키 발급
- 📊 **내 검색 통계** — 검색 횟수·캐시 적중률·인기 단어
- (Phase 4-1) ⬇ **로컬 HUD 다운로드** — .exe 파일

## 핵심 사용 흐름 — 로컬 HUD로 검색

이게 hudtyping의 진짜 가치. 한글에서 Alt+Tab 없이 단어 검색.

### 준비 (한 번만)
1. **API 키 발급**: 대시보드 → 🔑 → "내 노트북" 같은 이름 입력 → 발급 → **평문 키를 즉시 복사** (한 번만 보임)
2. **로컬 HUD 설치**: [local-hud-setup.md](local-hud-setup.md) 참고
3. **HUD 트레이 → 설정 → API 키 입력란에 붙여넣기**

### 매일 사용
1. 한글에서 회의록 작성 중
2. 모르는 단어 만남 (예: "기각")
3. 단어를 마우스로 **블록 선택** → **F2**
4. **HUD에 결과 카드 즉시 표시** (사과(沙果) / 사과(謝過) 처럼 한자별로)
5. 한글로 다시 돌아와서 작성 계속 (Alt+Tab 0회)

또는 블록 잡기 귀찮으면 **F3** — 커서 앞 단어 자동으로 잡아 검색.

   *📷 이미지 자리: `screenshots/10-hud-overlay.png`*

## 웹에서 검색하기 (보조 기능)

로컬 HUD 없이 빠르게 단어만 찾고 싶을 때:

1. 대시보드 → 🔍 **우리말샘 검색**
2. 검색바에 단어 입력 + Enter
3. 결과 카드 표시
4. 같은 단어 두 번째부터 **"캐시 ✓ 적중"** 표시 = 응답 더 빨라짐

   *📷 이미지 자리: `screenshots/04-search-page.png`*

## 통계 보기

대시보드 → 📊 **내 검색 통계**:
- **총 검색 횟수**: 웹+로컬 HUD 합산
- **캐시 적중률**: 같은 단어 반복 검색이 얼마나 빨라졌는가
- **첫 검색일**: 처음 사용한 날짜
- **최근 검색어 10건**: 시간순
- **자주 찾은 단어 top 10**: 사용 패턴

   *📷 이미지 자리: `screenshots/05-stats.png`*

## API 키 관리

### 새 키 발급
- 디바이스(노트북·회사 PC·집 PC)별로 따로 발급 추천
- 이름은 식별 가능한 거 (예: "내 노트북 2025")

### 키 잃어버렸을 때
- **다시 못 봐**. 발급 시 1회만 보임.
- 잃어버린 키 **삭제** → 새 키 발급 → 로컬 HUD 설정에 새 키 입력

### 키 누군가에게 노출됐을 때
- 즉시 **삭제** 클릭. 그 키를 쓰던 디바이스 모두 즉시 인증 실패.
- 새 키 발급 후 본인 디바이스에 다시 입력.

   *📷 이미지 자리: `screenshots/06-api-keys.png`*

### Q. 가입했는데 승인이 안 와요

### Q. 로컬 HUD에서 "API 키가 유효하지 않아요" 떠요
A. 키를 잘못 복사했을 가능성. SaaS의 🔑 페이지에서 새 키 발급 후 다시 붙여넣기. 또는 SaaS에서 "삭제됨" 처리됐을 수도 있음.

### Q. 일일 검색 한도가 있나요?
A. 1년 무료 운영 동안 사실상 무제한. 우리 SaaS 측 한도는 일 5만 호출인데 캐시 덕분에 사용자 1만 명 써도 안 채워짐. 1년 후 유료화 도입 시점에 한도 정책 변경 안내.

### Q. 모바일/태블릿에서도 쓸 수 있나요?
A. 웹 검색은 가능 (브라우저로 SaaS 접속). 로컬 HUD는 데스크톱 전용 (Windows .exe).

### Q. 데이터(검색 기록)는 어떻게 관리되나요?
A. 우리 DB(Neon)에만 저장. 외부 분석 도구로 안 보냄. 계정 삭제 시 cascade로 검색 기록도 함께 삭제됨 (`ON DELETE CASCADE`).
