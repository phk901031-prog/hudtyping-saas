# hudtyping 사용자 가이드

## 시작 순서

1. 웹에서 회원가입합니다.
2. 빠른 승인이 필요하면 카카오톡 `papawheels`로 가입 이메일과 성명을 보냅니다.
3. 승인 후 대시보드에서 API 키를 발급합니다.
4. Windows 앱을 설치하고 HUD 설정에 API 키를 입력합니다.

## 커서 앞 검색

한글 문서에서 단어 뒤에 커서를 두고 지정한 단축키를 누르면 커서 앞 단어를 자동으로 잡아 검색합니다.

- 기본 단축키: `F3`
- 추천 단축키: `Insert`
- 설정 위치: HUD 상단 `설정` 버튼

### 연속 확장 검색

같은 단축키를 연속해서 누르면 띄어쓰기를 넘어 검색어가 앞쪽으로 확장됩니다.

예시:

```text
회의 안건 정리|
```

- 1회: `정리`
- 2회: `안건 정리`
- 3회: `회의 안건 정리`

v0.2.2부터는 검색 결과가 뜬 뒤에 확장하는 방식이 아니라, 누른 횟수만큼 먼저 확장한 뒤 한 번만 검색합니다.
