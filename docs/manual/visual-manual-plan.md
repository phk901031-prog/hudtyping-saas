# HUDTyping 시각 매뉴얼 제작안

## 목적

처음 설치하는 사용자가 글을 길게 읽지 않아도 `설치 -> API 키 입력 -> 커서 앞 검색` 흐름을 따라 할 수 있게 만든다.

## 이미지 매뉴얼

권장 구성: 4장 카드형 이미지

1. 가입 승인
   - 문구: `회원가입 후 승인을 기다려주세요. 빠른 승인은 카카오톡 papawheels로 연락`
   - 화면: 웹 가입/대시보드 진입 이미지

2. API 키 입력
   - 문구: `대시보드에서 API 키를 발급하고 HUD 설정에 붙여넣기`
   - 화면: API 키 카드 + HUD 설정창

3. 커서 앞 검색
   - 문구: `단어 뒤에 커서를 두고 지정 키를 누르세요`
   - 화면: `회의 안건 정리|` 예시와 HUD 결과

4. 연속 확장
   - 문구: `같은 키를 연속으로 누르면 검색어가 앞 단어까지 확장됩니다`
   - 화면: `정리 -> 안건 정리 -> 회의 안건 정리`

## 영상 매뉴얼

권장 길이: 45~60초

### 컷 구성

1. 0~5초
   - 화면: 한글 회의록 작성 화면
   - 자막: `회의록 작성 중, 단어 뜻을 확인해야 할 때`

2. 5~12초
   - 화면: 커서가 단어 뒤에 있는 장면
   - 자막: `단어 뒤에 커서를 둡니다`

3. 12~20초
   - 화면: Insert 키 입력
   - 자막: `지정 키를 누르면 HUD가 바로 검색합니다`

4. 20~32초
   - 화면: HUD 결과 표시
   - 자막: `Alt+Tab 없이 뜻을 확인합니다`

5. 32~45초
   - 화면: Insert 연속 입력
   - 자막: `연속 입력하면 정리 -> 안건 정리 -> 회의 안건 정리로 확장`

6. 45~60초
   - 화면: 웹 대시보드와 카카오톡 문의 안내
   - 자막: `승인과 문의는 카카오톡 papawheels`

## 제작 방법

- 이미지: 홈페이지의 `따라 하기` 섹션을 캡처해 카드형 이미지로 사용 가능
- 영상: OBS 또는 Windows 캡처 도구로 한글 + HUD 사용 장면 녹화
- 편집: Clipchamp 또는 CapCut으로 자막만 얹어도 충분

## 톤

- 과장된 홍보 영상보다 실제 업무 화면 중심
- 말투는 짧게: `커서 두기`, `키 누르기`, `HUD 확인`
- 색상은 홈페이지와 동일한 종이색, 잉크색, 러스트 포인트 유지
