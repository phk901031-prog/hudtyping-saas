# 로컬 HUD 설치 가이드

> SaaS 가입 + 승인 + API 키 발급은 [user-guide.md](user-guide.md) 먼저 참고.

## 시스템 요구사항

- **운영체제**: Windows 10 또는 11
- **메모리**: 4GB 이상
- **인터넷**: 검색 시 SaaS 호출 필요 (오프라인 불가)
- **백신 프로그램**: .exe 첫 실행 시 경고 가능 (서명 인증서 미발급 상태) → "추가 정보" → "실행" 클릭

## 1. 다운로드

1. SaaS 메인 페이지(또는 대시보드 우측 상단) → **".exe 다운로드"** 클릭
2. 또는 **https://github.com/phk901031-prog/hudtyping/releases/latest** 직접 접속 → `hudtyping-Setup-X.X.X.exe` 받기

   *📷 이미지 자리: `screenshots/20-download-button.png`*

## 2. 설치

1. 다운받은 `.exe` 더블클릭
2. (Windows Defender 경고 시) "추가 정보" → "실행"
3. 설치 마법사 진행 → 기본 경로 그대로 → "설치"
4. 완료 후 **자동 실행됨** (또는 시작 메뉴에서 "hudtyping" 검색)

   *📷 이미지 자리: `screenshots/21-installer.png`*

## 3. 첫 실행 — API 키 입력

설치 직후 작은 HUD 창이 화면 어딘가에 떠. 그리고 **시스템 트레이**(작업표시줄 우측 하단)에 빨간 동그라미 + M 아이콘이 생김.

### 키 입력 방법
1. HUD 창의 ⚙ (설정) 버튼 클릭 — 또는 트레이 아이콘 우클릭
2. **API 키** 입력란 보임
3. SaaS의 🔑 페이지에서 발급받은 `hk_live_...`를 **그대로 붙여넣기**
4. **저장** 클릭 → "저장됨!" 표시

   *📷 이미지 자리: `screenshots/22-hud-settings.png`*

### 키가 없으면?
SaaS 가입 후 발급해야 함. [user-guide.md의 "API 키 관리" 섹션](user-guide.md#api-키-관리) 참고.

## 4. 단축키 사용

기본 단축키는 **F2** (블록 선택 검색) / **F3** (이전 단어 자동 검색)이지만,
**자유롭게 바꿀 수 있어요**. 평소 안 쓰는 키(예: **Insert**, **ScrollLock**, **Pause**)로 바꿔 두면 한글 작업 흐름과 부딪힐 일이 거의 없어요.

### 단축키 변경
1. HUD 설정 패널 (⚙ 또는 트레이 메뉴)
2. **단축키** 입력란 클릭
3. 원하는 키 한 번 누름 → 자동 저장

### 블록 선택 검색
1. 한글(또는 다른 어떤 텍스트 앱이든)에서 **단어를 마우스로 블록 선택**
2. 지정한 단축키 누름 (기본 F2)
3. HUD에 결과 카드 즉시 표시

### 이전 단어 자동 검색
1. 한글에서 어떤 단어 뒤에 커서 두기 (블록 안 잡아도 됨)
2. 지정한 단축키 누름 (기본 F3)
3. 자동으로 커서 앞 단어를 잡아 검색

   *📷 이미지 자리: `screenshots/23-hotkey-demo.gif`*

### 단축키 충돌
다른 프로그램이 같은 키를 이미 쓰고 있으면 HUD가 등록 못 해요. 다른 키로 변경하면 해결.

## 5. HUD 옵션

### 투명도 조절
트레이 아이콘 우클릭 → **투명도** → 높음(30%) / 보통(60%) / 낮음(85%) / 불투명

### 클릭 통과 모드
HUD 위에서 클릭이 한글에 그대로 전달됨. 검색 결과만 보고 한글에서 작업 계속할 때 편함.
- 트레이 → **클릭 통과 모드** 체크

### 보이기/숨기기
- 트레이 아이콘 좌클릭으로 토글
- 또는 트레이 우클릭 → "오버레이 보이기/숨기기"

## 6. 종료

- 트레이 아이콘 우클릭 → **종료**
- (그냥 X 버튼은 트레이로 숨기기. 진짜 종료는 메뉴에서)

## 자주 발생하는 문제

### Q. 백신이 .exe를 차단해
A. 코드 서명 인증서 미발급 상태라서 그래 (1년 무료 운영 단계라 인증서 비용 절감 중). "추가 정보" → "실행" 또는 백신 예외 처리.
- 1년 후 유료화 도입 시 코드 서명 인증서 발급 예정.

### Q. 단축키가 안 먹혀요
A. 다른 프로그램이 같은 키를 점유 중일 가능성이 커요. HUD 설정에서 평소 안 쓰는 다른 키(예: Insert, Pause)로 변경해 보세요. 그래도 안 되면 관리자 권한으로 HUD 재실행.

### Q. "API 키가 유효하지 않습니다" 떠요
A. 다음 중 하나:
- 키를 잘못 복사 (앞뒤 공백)
- SaaS에서 키를 삭제함 → 새 키 발급
- 가입 승인 안 됨 → SaaS 대시보드에서 확인

### Q. "서버 응답이 너무 느려요" 떠요
A. 인터넷 연결 또는 SaaS 서버 상태 확인. 1년 무료 운영 중이라 가끔 Vercel 콜드 스타트로 첫 요청이 1~2초 걸릴 수 있음.

### Q. 한자가 깨져 보여요
A. Windows의 동아시아 언어팩 설치 필요. **설정 → 시간 및 언어 → 언어** → 한국어 외에 일본어/중국어(간체) 추가하면 한자 표시 잘 됨.

### Q. 결과가 안 떠요 (단축키는 누름)
A. 1) 클립보드 권한 문제. 다른 클립보드 매니저(예: ditto)와 충돌일 수 있음.
2) 한글 워드프로세서가 클립보드 차단할 때 있음. 메모장에서 동일 동작 테스트.
