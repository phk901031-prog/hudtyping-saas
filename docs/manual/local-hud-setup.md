# 로컬 HUD 설치 가이드

## 요구 사항

- Windows 10 또는 11
- 인터넷 연결
- hudtyping 가입 승인
- 대시보드에서 발급한 API 키

## 설치

1. 웹 메인 화면에서 Windows 앱을 다운로드합니다.
2. `hudtyping-Setup-X.X.X.exe`를 실행합니다.
3. Windows Defender 또는 백신 경고가 나오면 설치 문제 해결 안내에 따라 허용합니다.
4. 설치 후 HUD 상단 `설정`에서 API 키를 입력하고 저장합니다.

## 단축키 설정

HUD 설정에서 `커서 앞 검색` 단축키를 바꿀 수 있습니다.

- 기본값: `F3`
- 추천값: `Insert`
- 피해야 할 키: `Enter`, `Tab`, `Ctrl+C`, `Alt+Tab` 등 시스템/편집 단축키

## 사용법

1. 한글 문서에서 검색할 단어 뒤에 커서를 둡니다.
2. `커서 앞 검색` 단축키를 누릅니다.
3. 같은 키를 연속해서 누르면 검색어가 앞쪽 단어까지 확장됩니다.

예시:

```text
회의 안건 정리|
```

- 1회: `정리`
- 2회: `안건 정리`
- 3회: `회의 안건 정리`

## 오류 메시지

`우리말샘 응답 지연 중`이 표시되면 우리말샘 또는 서버 응답이 느린 상태입니다. 잠시 뒤 다시 검색해주세요.
